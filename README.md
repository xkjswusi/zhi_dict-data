# zhi-dict-wave1 — the adapted dataset of Zhi Dict

This is the dictionary data shipped in the Zhi Dict Android app, published under CC BY-SA 4.0 as the
share-alike adaptation of CC-CEDICT.

## What it is

- **2133 entries and 4522 senses** of Chinese definitions, explanations and example
  sentences for learners, one row per entry, sense and example in `tables/`.
- **Content hash** `b04357f5771f1449883d57b22f198860d2b73dd82e8e7d73bc0223b8c0fb4282` (the app pins this value) and **file sha256** `eae859ae713603b7d15d544e0024074f5e56b3f42994537e00bbb52adae71f16`.
- **Source:** CC-CEDICT snapshot `cedict_1_0_ts_utf-8_mdbg.txt.gz`, sha256 `80a3b2c91524ce4ab5d22a90b1cfdeddb7918c36cd29ebf635f958e5b67ae6cf`, included in `source/` because
  MDBG serves only its latest release.

## How it was made, and its review state

The Chinese definitions, explanations and examples were **generated by an AI model** from the
CC-CEDICT English glosses. Machine checks ran over every record. Some senses were edited by AI
adjudication, and part of the data had one external AI audit. **No person has reviewed this data:**
every record is marked `unreviewed`, and the `meta` table and `provenance` rows say which process
touched what. Simplified text is converted by program from the traditional text, with rule
corrections.

## Files

- `zhi-dict-wave1.sqlite`: the runtime database (SQLite, schema 2).
- `tables/*.tsv`: every table as UTF-8 TSV with a header row, rows in primary-key order. An empty
  cell is NULL; backslash, tab, CR and LF inside a value are written `\\`, `\t`, `\r`, `\n`.
- `source/`: the CC-CEDICT snapshot.
- `SHA256SUMS`: sha256 of every other file.

Row counts: aliases 78, classifiers 540, common_words 2503, entries 2133, examples 3702, glosses 7828, meta 18, pron_variants 40, provenance 188, search_pinyin 2172, senses 4522, xrefs 727.

## Rebuilding

The tooling that compiles this database from its inputs is not yet public. Rebuilding it would take
the snapshot in `source/` plus the generated batches, the frequency spine and the compiler, and those
are published once the project's code licence is decided. Until then, this tree is the release form
of the data, and `SHA256SUMS` and the content hash above identify it.
